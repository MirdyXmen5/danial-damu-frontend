## 🔍 Если что-то не работает

### Проблема: Белая страница админа

**Решение:**
1. Откройте F12 → Console
2. Ищите красные ошибки
3. Скопируйте ошибку и посмотрите:
   - `Failed to fetch 'api/images/'` → Проверьте VITE_API_URL на Render
   - `401 Unauthorized` → Может потребоваться переlogined
   - `CORS error` → Проверьте CORS_ALLOWED_ORIGINS на backend

### Проблема: Login не работает

**Решение:**
1. Откройте Network в DevTools
2. Введите credentials и нажмите "Войти"
3. Найдите запрос `api/token/` в Network
4. **Проверьте:**
   - Если `404` → Backend URL неправильный
   - Если `401` → Неверные credentials
   - Если `200` → Но не работает → Ошибка в JS коде

### Проблема: Не загружаются изображения

**Решение:**
1. Network → `api/images/` → Preview
2. **Проверьте:**
   - Есть ли ошибка JSON?
   - Правильно ли структурирован ответ?
3. Если ошибка backend → проверьте logs на backend Render сервисе
